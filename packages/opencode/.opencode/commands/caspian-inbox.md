description: List Caspian inbox messages (email + configured channels)
---

Load the **caspian-inbox** skill (alias caspian:Inbox), then call tool
`caspian_inbox` with `list` true to show connections and recent
conversations/messages across configured Caspian channels.

Optional arguments (parse from below if present):
- channels (comma-separated)
- conversationLimit
- messageLimit

Arguments:
$ARGUMENTS
